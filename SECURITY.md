# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull
requests.**

If you discover a vulnerability in the ProxyJam API, platform, or these docs, report it privately
through one of these channels:

- GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
  — open the **Security** tab and choose **Report a vulnerability**.
- Email **security@proxyjam.com**.

Include a description of the issue and steps to reproduce. We aim to acknowledge reports within a
few business days.

## Handling secrets

This is a public repository. Never commit API keys, signing secrets, or other credentials to pages,
examples, or screenshots. Use placeholders such as `pj_live_...` in documentation examples.
