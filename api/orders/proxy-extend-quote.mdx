---
title: "Extension quote"
description: "Price, discount and each payment method's fee for extending a proxy, before you pay."
api: "GET /orders/{order_id}/extend/quote"
---

Returns what an extension costs and what each payment method adds on top, so a checkout screen can show the breakdown before the customer picks a method. Nothing is charged or reserved.

## Path parameters

<ParamField path="order_id" type="string" required>
  UUID of the order.
</ParamField>

## Query parameters

<ParamField query="months" type="integer">
  Months to extend, for static proxies.
</ParamField>

<ParamField query="tarification_index" type="integer">
  Tarification to re-bill, for mobile rotating proxies.
</ParamField>

<Note>
  Provide exactly one of `months` or `tarification_index`. The same errors as [Extend proxy](/api/orders/proxy-extend) apply — a proxy that cannot be extended cannot be quoted.
</Note>

## Response

<ResponseField name="order_id" type="string" />
<ResponseField name="months" type="integer | null" />
<ResponseField name="tarification_index" type="integer | null" />
<ResponseField name="currency" type="string" />
<ResponseField name="price" type="string">List price.</ResponseField>
<ResponseField name="discount" type="string">The original order's promo code, carried over (static proxies).</ResponseField>
<ResponseField name="amount" type="string">`price − discount`.</ResponseField>
<ResponseField name="methods" type="object[]">
  One entry per payment method you may use: `payment_method`, `name`, `payment_fee`, `total` (`amount + payment_fee`), `available`, and `unavailable_reason` — `amount_below_minimum`, `amount_above_maximum` or `currency_not_supported` when `available` is `false`. The wallet has no fee and no minimum.
</ResponseField>
