---
title: "Get extension"
description: "The state of one paid proxy extension."
api: "GET /orders/{order_id}/extensions/{extension_id}"
---

Returns one [extension](/api/orders/proxy-extend#extension-object). Poll it after the customer returns from the payment page, or listen for `order_update` WebSocket events whose `event_type` starts with `orders.extension_`.

## Path parameters

<ParamField path="order_id" type="string" required>UUID of the order.</ParamField>
<ParamField path="extension_id" type="string" required>UUID of the extension.</ParamField>

## Response

The extension object. `404` if it does not exist, belongs to another order, or is not yours.

  -H "X-API-Key: pj_AbCdEf..."
