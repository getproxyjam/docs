---
title: "List orders"
description: "Retrieve a paginated list of orders for the authenticated user."
api: "GET /orders"
---

Returns the user's orders, sorted by creation date descending.

## Query parameters

<ParamField query="limit" type="integer" default="50">
  Number of results to return. Min `1`, max `100`.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of results to skip for pagination.
</ParamField>

<ParamField query="status" type="string">
  Filter by order status. One of: `new`, `waiting_payment`, `paid`, `provisioning_failed`, `provisioned`, `cancelled`, `refunded`, `expired`. See [Order statuses](/api/orders/create-order#order-statuses).
</ParamField>

## Response

<ResponseField name="orders" type="array">
  List of order objects. Same shape as [Create order response](/api/orders/create-order#response).
  <Expandable title="Payment link">
    <ResponseField name="payment_url" type="string">
      Where to send the customer to pay. Set while `status` is `waiting_payment` for any external payment method (card checkout, crypto, SBP, Telegram Stars), `null` otherwise.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of orders matching the filter.
</ResponseField>

<Note>
  To find orders that still wait for payment, filter with `status=waiting_payment`: each one carries the `payment_url` to send the customer to. When the payment window closes unpaid, the order becomes `expired` and `payment_url` is `null`. A payment that still arrives after that is credited to your account balance and the order stays `expired`. See [Payment methods](/overview/payment-methods).
</Note>

## Example

<CodeGroup>

```bash cURL
curl "https://api.proxyjam.com/public/v1/orders?limit=10" \
  -H "X-API-Key: pj_AbCdEf..."
```

```python Python
from proxyjam import ProxyJamClient

with ProxyJamClient(api_key="pj_live_...") as proxyjam:
    page = proxyjam.orders.list(limit=10, offset=0)
    for order in page.orders:
        print(order.id, order.status, order.country)
    print(f"total: {page.total}")
```
