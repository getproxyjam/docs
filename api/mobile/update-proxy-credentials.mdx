---
title: "Update proxy credentials"
description: "Replace IP allowlist and/or login/password pairs on a mobile rotating proxy."
api: "POST /orders/{order_id}/credentials"
---

Replaces the credential set on the upstream pool. You can update the allowlist of source IPs, the list of login/password pairs, or both in one call.

Send no body to get a new random password. The login stays the same and the old password stops working at once. A body with neither field (`{}`) does the same.

A list you send must not be empty: `{"ips": []}` or `{"passwords": []}` is refused (`422`) rather than clearing the list. Each list is capped at 20 entries by the upstream pool.

## Path parameters

<ParamField path="order_id" type="string" required>
  UUID of the order backing the mobile rotating proxy.
</ParamField>

## Request body

Optional. Omit the body to get a new random password.

<ParamField body="ips" type="array">
  Allowed source IPs for IP-allowlist authentication. Omit to leave the existing list unchanged.
</ParamField>

<ParamField body="passwords" type="array">
  Login/password pairs, each shaped `{"login": "...", "password": "..."}`. Omit to leave the existing list unchanged.
</ParamField>

## Response

Live snapshot of the mobile rotating proxy with the updated credentials applied. Same shape as the mobile branch of [Get order](/api/orders/get-order#response-mobile).

## Rate limit

10 requests a minute per caller, with a burst of 5 — it waits on the upstream pool, whose capacity every customer shares. Past that the call answers `429` with `Retry-After` in seconds; see [Rate limits](/overview/errors#rate-limits).

## Example: a new password

The response carries the new `password`; `username` is unchanged.

<CodeGroup>

```bash cURL
curl -X POST "https://api.proxyjam.com/public/v1/orders/997b4450-e7ae-4ad9-8a25-996e582049c9/credentials" \
  -H "X-API-Key: pj_AbCdEf..."
```

```python Python
from proxyjam import ProxyJamClient

with ProxyJamClient(api_key="pj_live_...") as proxyjam:
    proxy = proxyjam.proxies.rotate_credentials("997b4450-e7ae-4ad9-8a25-996e582049c9")
    print(proxy.username, proxy.password)
```

</CodeGroup>

## Example: allowlist and pairs

<CodeGroup>

```bash cURL
curl -X POST "https://api.proxyjam.com/public/v1/orders/997b4450-e7ae-4ad9-8a25-996e582049c9/credentials" \
  -H "X-API-Key: pj_AbCdEf..." \
  -H "Content-Type: application/json" \
  -d '{
    "ips": ["203.0.113.10", "203.0.113.11"],
    "passwords": [
      {"login": "scrape_bot", "password": "s3cret"}
    ]
  }'
```

```python Python
from proxyjam import ProxyJamClient

with ProxyJamClient(api_key="pj_live_...") as proxyjam:
    proxy = proxyjam.proxies.rotate_credentials(
        "997b4450-e7ae-4ad9-8a25-996e582049c9",
        ips=["203.0.113.10", "203.0.113.11"],
        passwords=[{"login": "scrape_bot", "password": "s3cret"}],
    )
    print(proxy.username, proxy.whitelisted_ips)
```
