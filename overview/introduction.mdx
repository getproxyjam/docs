ProxyJam is a proxy service. What is on sale today is [static residential (ISP)](https://proxyjam.com/isp-proxies/): one IP address registered to a named internet carrier, hosted on server infrastructure, priced per IP per month and held for the whole period you pay for; the [United States catalogue](https://proxyjam.com/isp-proxies/usa/) names the carrier behind every block. Rotating residential and datacenter proxies are catalogued but not orderable, and ordering mobile rotating is gated per account — which is why this documentation still describes the mobile endpoints in full. This API gives you the same catalogue the dashboard sells from: browse offers, place orders, and manage the proxies you hold — all through a single REST API authenticated with an API key.

## Base URL

All public API requests go to:

```
https://api.proxyjam.com/public/v1
```

## Authentication

Every request is authenticated with an API key in the `X-API-Key` header:

```
X-API-Key: pj_AbCdEf...
```

Get your key from your [personal account](https://app.proxyjam.com/apikey). See [Authentication](/overview/authentication) for details.
