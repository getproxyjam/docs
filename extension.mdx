ProxyJam Connector is a browser extension for Chrome, Microsoft Edge, and Firefox. It stores your proxy profiles, switches between them in one click, and can route individual sites through specific proxies using rules you define.

<Note>
  The extension is a separate product from the ProxyJam proxy service documented in the rest of this site. It works with whatever proxies you configure, whether you bought them from ProxyJam or somewhere else, and installing it does not sign you in to anything.

  It has one optional connection to the service: the [ProxyJam account tab](/extension/proxyjam-account), where you can sign in, buy a proxy, and connect to it. That tab is the only part of the extension that talks to a server, and it sends nothing until you sign in. Everything else works without it.
</Note>

## How it stores your data

Everything lives in your browser's local extension storage on your own device. There is no sync, no telemetry, and no remote configuration.

The extension is **offline by default**: it makes no network request at all until you opt into one of the optional checks or sign in to a ProxyJam account, and each of those additionally requires you to grant a permission. Nothing is sent in the resting state.

Proxy passwords are never shown back to you in the interface, are redacted from every log, and are excluded from exports unless you explicitly include them.

## Proxy modes

The popup switches between four modes:

| Mode | What it does |
| --- | --- |
| Direct | No proxy. Traffic goes out as normal. |
| A saved profile | All traffic goes through that one proxy. |
| Auto | Traffic is routed per site by your [auto-switch rules](/extension/auto-switch-rules). |
| System | Defers to the operating system's proxy settings. |

Your choice survives a browser restart.

## Profiles

A profile is one proxy: scheme, host, port, and optionally a username and password. Supported schemes are `http`, `https`, `socks4`, `socks5`, and `quic`.

Profiles also carry a name, notes, a colour tag, a favourite flag, a remote-DNS flag, and an optional [failover target](/extension/health-checks). There is no limit on how many you keep.

## What the extension will not do

It never fakes a capability. Where a browser cannot do something, the interface says so rather than guessing.

| Capability | Chrome and Edge | Firefox |
| --- | --- | --- |
| Switching, rules, bypass list | Yes, compiled to a PAC script | Yes, resolved per request |
| Proxy authentication without a dialog | Yes | Yes |
| SOCKS5 username and password | No. Chrome itself does not support it, so credentials are stored but ignored — use an IP allowlist instead | Yes |
| URL and path rules on HTTPS | Hostname only. Chrome strips the path before the PAC script sees it | Full URL |
| Per-container proxies | No. Chrome exposes no container information to extensions, so the build carries no Containers tab | Yes |
| [DNS-leak verdict](/extension/dns-leak) | Reported as unavailable | Reported as unavailable |

## Import and export

The extension reads its own JSON, JSON backups from other proxy extensions, plain text, and CSV — detecting the format from the file's structure — and maps third-party rule patterns onto its own rule types. A pattern it cannot map is reported rather than approximated.

Exports are written as `proxyjam-connector.json`, `proxies.txt`, or `proxies.csv`. Passwords are stripped unless you opt in. You can also encrypt the whole export with a password, which produces a `proxyjam-connector.pjenc` file — the encryption runs entirely in your browser.

Full details: [Import / Export](/extension/import-export).
